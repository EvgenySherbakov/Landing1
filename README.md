# АкваБлеск — лендинг автомойки

Одностраничный адаптивный сайт (landing page) для автомойки. Чистый HTML/CSS/JS без зависимостей и сборки.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили и адаптивная вёрстка
- `script.js` — меню, анимации появления, маска телефона, отправка формы

## Разделы

- Шапка с навигацией и телефоном
- Hero-блок с призывом к действию и статистикой
- Услуги (6 карточек)
- Тарифы (3 пакета)
- Преимущества
- Отзывы клиентов
- Контакты с формой онлайн-записи
- Подвал и плавающая кнопка WhatsApp

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем перейдите на http://localhost:8000

## Настройка

Перед публикацией замените заглушки на свои данные:

- Название и логотип («АкваБлеск», 💧)
- Телефон `+7 (495) 123-45-67`, e-mail, адрес
- Ссылку WhatsApp в `index.html`
- Цены в разделе «Тарифы»
- Подключите обработку формы к вашему backend/CRM в `script.js`
